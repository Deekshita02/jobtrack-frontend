# JobTrack — Frontend

React frontend for JobTrack, a full-stack job application tracker. Connects to the [JobTrack backend](https://github.com/Deekshita02/jobtrack) (Spring Boot + PostgreSQL + JWT auth).

## Features

- Login and registration screens, backed by JWT authentication
- Add, edit, delete, and filter job applications by status
- Auth token stored client-side and automatically attached to every API request
- Automatic logout if the session token is invalid or expired

## Tech Stack

React.js · Fetch API · CSS
